= 将 vCenter 服务器实例融合到具有 VMFS 数据存储的 VCF 管理域的部署工作流
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
将包含 NetApp ONTAP VMFS 数据存储的现有 vSphere 集群收敛到 VMware Cloud Foundation 管理域。您将审查配置要求，部署 ONTAP tools 并配置 VMFS 数据存储，然后使用 VCF Installer 工具验证并使用现有组件、部署所需的新组件并配置平台。

此工作流还用于将任何受支持的 VMFS 数据存储用作 VCF 管理域的主体存储。

有关转换过程的概述，请参阅 VMware 文档： https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["将现有虚拟基础设施融合到 VCF"]。

[role="quick-margin-para"]
查看使用 VMFS 数据存储将 vCenter 服务器实例融合到 VCF 管理域的关键要求。

[role="quick-margin-para"]
