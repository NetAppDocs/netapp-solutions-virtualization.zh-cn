= 将 iSCSI vVols 数据存储区添加为工作负载域中的补充存储的部署工作流程

:icons: font
:imagesdir: ../media/


[role="lead"]

[role="quick-margin-para"]
为 iSCSI 流量创建具有多个 LIF 的 SVM。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"]link:vmw-vcf-viwld-supp-iscsi-vvols-network.html["配置网络"]
[role="quick-margin-para"]
