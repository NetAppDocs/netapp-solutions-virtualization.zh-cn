= 借助 VMware Cloud Foundation 和 ONTAP 提升私有云体验
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
NetApp ONTAP 与 VMware Cloud Foundation (VCF) 集成，提供支持块、文件和对象协议的统一存储解决方案。ONTAP 的多租户功能使组织能够整合工作负载并简化管理，同时提供企业级数据保护和可用性。本文档概述了 VCF 以及如何使用 NetApp ONTAP 增强 VCF 环境中的存储功能。



[[introduction]]
== 简介

VCF 使组织能够轻松部署和管理私有云环境。开箱即用，它提供虚拟机、Kubernetes、容器和网络即服务，并能够扩展到在自助服务门户中以目录项的形式提供其他服务。通过将 NetApp ONTAP 用作 VCF 中的存储解决方案，组织可以在管理工作负载方面实现更大的灵活性、可扩展性和效率。



[[introduction-to-netapp-ontap]]
== NetApp ONTAP简介

NetApp ONTAP 是一款全面的数据管理软件，可在广泛的产品线中提供高级存储功能。ONTAP 可用作软件定义存储、通过主要云提供商提供的第一方服务以及 NetApp ASA（针对块优化进行分解）、AFX（针对非结构化数据进行分解）、AFF 和 FAS（统一）平台的存储操作系统。ONTAP 为各种用例（包括 VMware 虚拟化）提供高性能和低延迟，而不会形成数据孤岛。与在计算资源上创建虚拟机的方式类似，ONTAP 允许创建存储虚拟机（SVM），用于创建和管理存储资源。ONTAP 提供统一存储解决方案，支持多种协议，包括 NFS、SMB、iSCSI、FC、NVMe/TCP、NVMe/FC 和 NVMe/RDMA。这种灵活性使组织能够整合工作负载并简化管理，同时提供企业级数据保护和可用性。



[[introduction-to-vmware-cloud-foundation]]
== VMware Cloud Foundation 简介

VMware Cloud Foundation (VCF) 使组织能够创建虚拟私有云，在其中可以将虚拟机、Kubernetes 集群、容器、网络和存储作为服务使用，无论是针对 AI 工作负载、DevOps，还是传统的基于虚拟机的工作负载。

VCF 部署到全新环境，或将现有 vSphere 环境扩展为完整的私有云。一组计算主机构成一个 vSphere 集群，一组 vSphere 集群构成一个 VCF 域，一组 VCF 域构成一个 VCF 实例。一个机群由一个或多个 VCF 实例组成。VCF 私有云环境使用一个或多个机群创建。操作和自动化在机群级别处理，而 VCF 实例是部署单元。

A vSphere 命名空间用于设置工作负载的资源限制。A vSphere Zone 是一组 vSphere 集群，可用于为在该区域中运行的工作负载提供高可用性和灾难恢复功能。

image:vmware-vcf-overview-components.png["VMware 云基础组件"]

在 VCF Automation 中，区域是共享相同 NSX 基础架构的一个或多个 VCF 域的 vSphere 区域集合。组织是一个或多个区域的用户和资源的逻辑分组。组织可以细分为多个项目，每个项目都有自己的中转网关和外部连接。项目具有一个或多个命名空间，可用于为项目中运行的工作负载提供隔离和资源分配。

命名空间是项目中资源分配的基本单位。每个命名空间都映射到虚拟私有云 (VPC)，可用于为命名空间中运行的工作负载提供隔离和资源分配。

命名空间是使用专用 VPC 或共享 VPC 创建的。专用 VPC 是专用于单个命名空间的 VPC，而共享 VPC 是可供多个命名空间使用的 VPC。子网是在部署工作负载的 VPC 中创建的。

存储由在 vCenter 中定义的基于存储策略的管理 (SPBM) 策略使用。SPBM 可以使用一组规则来创建，这些规则定义了工作负载的存储要求。数据存储通常被标记并用于创建与不同工作负载的特定需求相匹配的存储策略。

需要相关性和反相关性规则的工作负载由基础架构策略管理，这些策略使用 vCenter 计算策略来定义工作负载在特定主机或集群上的放置。可以使用基础架构策略来确保根据工作负载的需求将其放置在特定主机或集群上。



[[vcf-domains]]
== VCF 域

域是 VCF 内的基础构造，可将资源组织成不同的、独立的组。域有助于更有效地组织基础设施，确保资源得到有效利用。每个域都部署有自己的计算、网络和存储元素。

image:vmware-vcf-overview-domains.png["VMware 云域"]

具有 VCF 的域主要有两种类型：

* *管理域* – 管理域包括负责 VCF 环境核心功能的组件。这些组件处理资源调配、监控、维护等基本任务，并包括第三方插件集成，如 NetApp ONTAP Tools for VMware。可以使用 VCF 安装程序设备部署管理域，以确保遵循最佳实践，或者可以将现有 vCenter 环境转换为 VCF 管理域。
* *工作负载域* – 工作负载域旨在成为专用于特定运营需求、工作负载或组织的资源池。工作负载域可通过 OPS Manager 轻松部署，有助于自动完成一系列复杂的任务。在 VCF 环境中最多可以配置 24 个工作负载域，每个工作负载域代表一个应用程序就绪的基础架构单元。每个工作负载域都有自己的 NSX 基础架构，或者共享现有的 NSX 基础架构，具体取决于它是单区域还是多区域部署。




[[storage-with-vcf]]
== 使用 VCF 存储

域功能的核心是它们消耗的存储空间。虽然 VCF 包含用于超融合用例的基于 CPU 核心的 vSAN 容量，但它也支持各种外部存储解决方案。对于在现有存储阵列上投入大量资金或需要支持超出 vSAN 能力范围的协议的企业来说，这种灵活性至关重要。  VMware 通过 VCF 支持多种存储类型。

VCF 存储主要有两种类型：

* *主体存储* – 此存储类型作为新 VCF 域的第 0 天部署的一部分，或作为现有 vCenter 的融合或导入的一部分自动进行配置。VCF 安装程序支持将 VSAN、FC 上的 VMFS 和 NFS 作为全新部署的一部分，而其他受支持的存储类型（包括 iSCSI 上的 VMFS 和 NVMe-oF）可以作为现有 vCenter 的融合或导入的一部分用作主体存储。ONTAP Tools for VMware vSphere 只能用于融合或导入现有 vCenter，以便为 VCF 域部署主体存储。作为附加集群部署的一部分或作为域扩展的一部分创建的任何数据存储均被视为主体存储。主体存储用于托管 VCF 管理组件，包括 vCenter、NSX Manager 和 SDDC Manager，以及在域内运行的工作负载。
* *补充存储* – 补充存储是在初始部署 VCF 域或融合或导入现有 vCenter 环境后配置的任何数据存储。可以使用 ONTAP Tools for VMware vSphere 创建补充存储，以便为 VCF 域部署数据存储区。创建补充存储是为了满足额外的容量需求、性能要求，或支持需要不同存储特性的特定工作负载。还可以创建补充存储以构建延伸集群，从而实现高可用性。


*支持VCF存储类型*

[cols="25%, 25%, 50%"]
|===


| *域名类型* | *主要存储* | *补充存储* 


| 管理域 | vSAN FC NFS 3 NFS 4.1 ^2^ iSCSI ^2^ NVMe/TCP ^2^ NVMe/FC ^2^ NVMe/RDMA ^2^ | vVols （FC、iSCSI 或 NFS）^1^ FC NFS 3 NFS 4.1 iSCSI NVMe/TCP NVMe/FC NVMe/RDMA 


| 工作负载域 | vSAN vVols (FC、iSCSI 或 NFS) ^1^ FC NFS 3 NFS 4.1 ^2^ iSCSI ^2^ NVMe/TCP ^2^ NVMe/FC ^2^ NVMe/RDMA ^2^ | vVols (FC、iSCSI 或 NFS) ^1^ FC NFS 3 NFS 4.1 iSCSI NVMe/TCP NVMe/FC NVMe/RDMA 
|===

[[why-ontap-for-vcf]]
== 为什么ONTAP适用于 VCF

除了涉及投资保护和多协议支持的用例之外，还有许多其他原因可以利用 VCF 工作负载域中的外部共享存储。可以假设为工作负载域配置的存储仅仅是托管虚拟机和容器的存储库。然而，组织的需求往往超出许可容量的能力，并需要企业存储。  ONTAP提供的存储分配给 VCF 内的域，易于部署并提供面向未来的共享存储解决方案。

image:why-ontap-for-vmware-002.png["为什么ONTAP适用于 VCF"]

有关下面列出的 VMware VCF 的主要ONTAP优势的更多信息，请参阅link:vmw-getting-started-overview.html#why-ontap-for-vmware["为什么选择ONTAP for VMware"]。

* 第一天以及扩展过程中的灵活性
* 将存储任务卸载到ONTAP
* 一流的存储效率
* 企业级数据可用性
* 高效的备份和恢复操作
* 整体业务连续性能力

[[summary]]
== 摘要

ONTAP提供了一个满足所有工作负载需求的平台，提供定制的块存储解决方案和统一的产品，以可靠、安全的方式为虚拟机和应用程序提供更快的结果。 ONTAP采用先进的数据缩减和移动技术，最大限度地减少数据中心占用空间，同时确保企业级可用性，使关键工作负载保持在线。此外，AWS、Azure 和 Google 支持NetApp驱动的外部存储，以增强 VMware 基于云的集群中的 vSAN 存储，作为其 VMware-in-the-Cloud 产品的一部分。总体而言，NetApp 的卓越功能使其成为 VMware Cloud Foundation 部署的更有效选择。
