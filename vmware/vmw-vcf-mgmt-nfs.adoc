= 使用 NFS 数据存储将 vCenter 服务器实例融合到 VCF 管理域的部署工作流程
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
将包含 NetApp ONTAP NFS 数据存储的现有 vSphere 群集融合到 VMware Cloud Foundation 管理域中。您将审查配置要求，部署 ONTAP tools 并置备 NFS 数据存储，然后使用 VCF Installer Tool 验证和使用现有组件、部署所需的新组件并配置该平台。

如果要将 ONTAP NFS 4.1 数据存储区用作 VCF 管理域的主存储，则此工作流也适用。

有关融合过程的概述，请参阅 VMware 文档： https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["将现有虚拟基础设施融合到 VCF"]。
