= 了解 Red Hat OpenShift 虚拟化
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Red Hat® OpenShift® 虚拟化使组织能够在统一的混合云应用平台上无缝迁移、运行和管理传统虚拟机 (VM) 以及现代工作负载。OpenShift 虚拟化可作为任何 OpenShift 订阅中包含的运算符使用。OpenShift 容器平台的这一附加组件为将虚拟机与容器化应用程序集成提供了强大的解决方案。它使用基于内核的虚拟机 (KVM)（这是受信任的 Linux 内核虚拟机管理程序，以强大的性能、可扩展性和稳定性著称），在 OpenShift 中以原生对象的形式为虚拟机提供企业级虚拟化。

image:redhat-openshift-044.png["OpenShift 虚拟化"]



[[key-features-of-red-hat-openshift-virtualization]]
== Red Hat OpenShift 虚拟化的主要功能

**混合工作负载：**迁移和运行具有云原生优势的虚拟机，并使用统一的工具集与容器和无服务器工作负载一起管理它们。

**逐步现代化：**通过采用容器、实施微服务或集成 AI，按照自己的步调进行现代化，而不会中断现有的 VM。

**Kubernetes 集成：** 利用 Kubernetes 自定义资源向 OpenShift 集群添加虚拟化功能。



[[capabilities-of-red-hat-openshift-virtualization]]
== Red Hat OpenShift 虚拟化的功能

**虚拟机管理：**创建和管理 Linux 和 Windows 虚拟机。

**统一工作负载：**在集群内同时运行 Pod 和 VM 工作负载。

**连接：**通过各种控制台和 CLI 工具访问虚拟机。

**VM Operations：**在节点之间导入、克隆和实时迁移虚拟机。

**资源管理：**处理连接到虚拟机的网络接口和存储磁盘。



[[compatibility]]
== 兼容性

虽然 OpenShift Virtualization 在概念上与 VMware vSphere 有所不同，但它提供了一个专为虚拟化管理员量身定制的现代平台，具备如下熟悉的功能：**实时迁移：** 相当于 vSphere 中的 vMotion。

**存储管理：** OpenShift 中的存储类与 vSphere 中基于存储策略的管理 (SPBM) 保持一致。

**持久存储：** 持久卷声明 (PVC) 和持久卷 (PV) 对应于 vSphere 中的数据存储。
