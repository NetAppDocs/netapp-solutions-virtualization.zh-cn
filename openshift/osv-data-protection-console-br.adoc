= 使用 NetApp Console Backup and Recovery Service 备份和还原虚拟机
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
使用 NetApp Console 备份和还原 Red Hat OpenShift Virtualization 中的 VM。此步骤介绍了如何通过 NetApp Console 的 Backup and Recovery 服务创建和管理备份与还原操作，并使用 Azure Blob Storage 容器作为备份目标。

NetApp Console 提供跨本地和云环境的存储和数据服务的集中管理。它提供统一控制、操作简便和安全管理。可从以下用户界面访问多种数据服务和管理功能：link:https://console.netapp.com["console.netapp.com"^]。有关 NetApp Console 的完整详细信息，请参阅 link:https://docs.netapp.com/us-en/console-family/["NetApp Console 文档"]。

本节重点介绍 Kubernetes 工作负载的 NetApp Backup and Recovery 数据服务，特别是 OpenShift 虚拟机。NetApp Backup and Recovery Service 使您能够使用单个界面发现、管理、创建保护策略并将其与 Kubernetes 应用程序和虚拟机相关联。有关完整指南，请参阅 link:https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html["NetApp Backup and Recovery 文档"]。



[[backup-and-recovery-workflow]]
== 备份和恢复工作流程

. *请确保您拥有控制台代理*
+
确保在运行 OpenShift 集群的环境中部署了控制台代理。有关安装控制台代理的详细信息，请参见 link:https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html#agent-console-deploy["NetApp Console Setup 文档"]。

+
.显示示例
[%collapsible]
====
在 NetApp Console 中，单击 Deploy Agent（如屏幕截图所示），然后在运行 OpenShift 集群的环境中部署代理。

在此示例中，我们选择了本地。复制代理安装程序 URL，使用 curl 命令在 vSphere 上运行的 Ubuntu 计算机上下载代理安装程序，然后运行安装程序以部署控制台代理。

使用 URL 中代理的 IP 地址进行注册。有关详细说明，请参阅 link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-on-prem-ova.html["文档"]。代理注册后，您可以在 NetApp Console 中看到它，如下面的屏幕截图所示。

. *将 Azure Blob 存储容器设置为 OpenShift 虚拟机备份和还原方案的备份目标。*
+
在此示例中，我们使用 Azure Blob Storage 作为备份目标。您还可以使用 AWS S3、Google Cloud Storage、StorageGRID 或 ONTAP 对象存储作为备份目标。

+
有关其他详细信息，请查看 link:https://docs.netapp.com/us-en/data-services-backup-recovery/br-start-setup.html#prepare-the-backup-destination["NetApp Console 文档"]。

+
若要在 NetApp Console 中将 Azure Blob 存储容器发现为备份目标，您需要从 Azure 门户获取以下信息。

+
[listing]
----
Application (Client) ID:
Client Secret:
Directory (tenant) ID:
----
+
若要获取这些值，请在Azure门户中执行以下操作。

+
.. 创建 Blob 存储容器。
.. 创建企业应用程序，将此应用程序所需的访问权限分配给 Blob 存储容器。获取此应用程序的应用程序 ID、目录 ID 和客户端密码，以便在 NetApp Console 中使用，将 Azure Blob 存储容器发现为备份目标。
+
.显示示例

.... 在订阅中创建资源组。
.... 创建存储帐户，然后创建 Blob 容器。

. *在 NetApp Console 中，发现 OpenShift 集群。*

.<strong>显示改进项</strong>
[%collapsible]
=====
image:osv-data-protection-console-043.png["保护每个具有多个磁盘的虚拟机时出错"]

[source, yaml]
----
- apiGroups:
  - groupsnapshot.storage.k8s.io
  resources:
  - volumegroupsnapshots
  verbs:
  - get
  - list
  - watch
  - create
  - delete
  - update
  - patch
- apiGroups:
  - groupsnapshot.storage.k8s.io
  resources:
  - volumegroupsnapshotcontents
  - volumegroupsnapshotcontents/status
  verbs:
  - get
  - list
  - watch
  - create
  - delete
  - update
  - patch
- apiGroups:
  - groupsnapshot.storage.k8s.io
  resources:
  - volumegroupsnapshotclasses
  verbs:
  - get
  - list
  - watch

----
